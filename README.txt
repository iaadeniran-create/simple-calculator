BEIJING TOUR - USER-ADDED PHOTO LOCATIONS

Files:
- index.html
- style.css
- script.js

Copy these files into the existing Beijing Tour project folder.
Keep the existing images/ folder (four Beijing photos and location-pin.png).
Open index.html using VS Code Live Server.

The form accepts a location title, local image, longitude and latitude.
When submitted, the new location appears as a marker on the map and a
clickable photo in the gallery. No projected X/Y coordinates are required.

IMPORTANT: New locations and uploaded photos are temporary browser-session
content. They disappear when the page reloads; this version does not upload
files to a server or save them to a database.
